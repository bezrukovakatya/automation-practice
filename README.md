\## Smoke Tests

1\. Успешная загрузка страницы логина

2\. Успешная авторизация (`standard\_user` / `secret\_sauce`)

3\. Загрузка главной страницы и отображение товаров

4\. Кнопка "Add to cart" работает

5\. Иконка корзины отображается
